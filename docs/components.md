# Components

Components are examples of the principles applied, not a mandate. Each names
the methods it assumes — change the method, change the component.

## Bounded action (MIG-C1, derived)

Assumes: touch on glass, or any method with a visible commit point.
Persistently visible bounded shape + label or universal icon
(derived — Norman signifiers, WCAG 2.5.8). Press feedback immediate and
visible without motion (derived — HIG feedback, WCAG 2.3.3).

## Edge bar (MIG-C2, proposed)

Assumes: glance-first usage. Persistent navigation in a top or bottom bar,
max 56pt tall, dark plate, 3–5 destinations. Never on the side vignettes
(reserved for status, not navigation).

## Status card (MIG-C3, proposed)

Assumes: glance distance. Dark plate in a corner, max two lines, 32sp+
numerals. Tapping a status card never navigates — it expands in place or
does nothing.

## Transient confirmation (MIG-C4, derived — HIG alerts, Material snackbars)

Assumes: any method. Auto-dismiss, no action required, never over the face
region. Errors persist until acknowledged ONLY if the user must act.
