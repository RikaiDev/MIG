# Foundations — Iconography

## Rules

- **I1 (borrowed — Material symbols, HIG SF Symbols philosophy).** One
  stroke width, rounded caps, filled variant for active states.
- **I2 (derived — WCAG non-text contrast 1.4.11).** Icons carry meaning:
  3:1 minimum against adjacent plate colors.
- **I3 (proposed).** Mirror-specific glyphs (presence, breath-hold progress,
  measurement lock) must be validated for recognition at a glance before use.
  No shipping an untested glyph as the only signifier.
