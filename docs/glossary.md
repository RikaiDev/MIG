# Glossary

- **Clear zone.** Central panel fraction reserved for reflection/measurement.
- **Edge bar.** Persistent top/bottom navigation, max 56pt.
- **Face ROI.** Camera-measured face region; never covered.
- **Glanceable.** Readable in a passing glance (1–2m): 32sp+ numerals, status only.
- **Reduced-motion twin.** Static variant of every animation.
- **Vignette.** Side regions for status, never navigation.
- **Zero-touch twin.** Voice/gesture path completing the same task.
