# 結束體驗並清除個人內容

## 使用指南

適用：任何會拍攝、個人化或改變共用狀態的工作階段。不適用：按完「完成」卻把資料留下的單一按鈕——離開不等於妥善結束。

## 互動示範

到 [Mirror Lab](/zh/lab.html#demo-states) 走退出分支：完成給收據、取消給 undo 窗口、離開逾時給可見倒數、下一位看到的重設畫面。

## 設計規格

- 結束態：完成（保留什麼＋怎麼刪）、取消（undo 窗口）、逾時（顯示倒數後清除）。
- 未確認就離開預設刪除；確認保留的顯示期限與刪除路徑。
- 下一位的重設畫面是設計出來的，不是殘留 UI。

## 驗證與證據

每次部署做退出走查：每一步中途放棄，確認無個人殘留；量下一位在重設畫面的困惑率。

## 已知缺口

各管轄區的保存期限文案未測試；共用家庭鏡（每天同一批人）需要另一套退出模型。
