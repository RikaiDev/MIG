# 多人靠近時決定誰在控制

## 使用指南

適用：任何超過一人看得到摸得到的鏡子。不適用：距離排名當主控（「最近的人贏」）——天天誤判，且無法向使用者解釋。

## 互動示範

到 [Mirror Lab](/zh/lab.html#demo-states) 角色扮演：第二人任務中加入，得到排隊／請求接管／重來三選；主控指示絕不在無明確動作下移動。

## 設計規格

- 同一時間一位可見主控者；加入提供排隊、確認後接管、重新開始。
- 接管盡量要求雙方確認；否則新人重開新工作階段。
- 主控閒置逾時回吸引態；離開預設結束工作階段。

## 驗證與證據

雙人測試中途加入；任何無聲轉移即不合格。相關框架：Proxemic Interactions（2011）提供靠近—參與—退出的距離／朝向／移動關係——當設計鷹架用，不證明「某固定距離等於同意」。

## 已知缺口

擁擠下的公平排隊因部署而異；群體同意（家庭、班級）流程尚未設計。
