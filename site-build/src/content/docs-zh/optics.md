# 鏡面光學與硬體基礎

限制或問題 → 為什麼會發生 → 設計上如何避免 → 哪些條件需要測試。本章所有規則都從這四步展開。

## 光線相加，不是圖層覆蓋

半透鏡同時反射前方環境，並讓後方顯示器的光穿出來。不同玻璃的反射、透射特性不同，也有針對強環境光設計的產品，不能一律假設 50：50。理解用的簡化模型：

> **看到的亮度 ≈ 環境與人體的反射亮度 × 反射率 ＋ 螢幕亮度 × 透射率**

```rule
id: OPT-01
title: 不要用螢幕黑底遮擋真實倒影
normative: must
evidence: physical
tech: optical
scope: 被動半透半反射鏡＋後方顯示器；不直接適用攝影機影像合成或具實體遮光能力的硬體。
statement: 不要把數位黑色區塊當成可以遮蔽實景的不透明底板。
why: 黑色只是降低顯示器發光，前方環境的反射仍然存在；這是光學疊加關係的直接推論，不是視覺風格偏好。
wrong: 設計稿以黑色卡片完全蓋住臉部，並假設裝到實體鏡面後也會如此。
fix: 調整內容位置與資訊量，並在實體鏡面測試；仍無法辨讀時，重新評估照明與硬體條件。
verify: 顯示全黑區塊，在鏡前移動明亮物件，確認其倒影仍如何出現在該區域；再檢查原設計是否錯誤依賴黑底遮擋。
gaps: 不同鍍膜比例下的殘留對比量測數據尚未收錄；需補現場量測。
```

```rule
id: OPT-02
title: 在倒影背景上測試辨讀，而不只檢查色碼
normative: should
evidence: physical
tech: optical
scope: 所有含文字與圖示的光學鏡面內容。
statement: 辨讀測試必須在至少三種倒影背景（淺色衣物、深色衣物、明亮窗戶或第二人）下進行；通過設計稿色碼對比不算通過。
why: 背景是使用者與現場，不是設計師選的；同一份 UI 的視覺競爭隨背景劇烈變化。
wrong: 只在深色實驗室外套前測試白色文字，就簽核全場域可用。
fix: 建立背景矩陣（衣物深淺 × 環境明暗 × 有無第二人），每格記錄可讀／勉強／不可讀。
verify: 現場抽換三種背景，量測任務辨讀成功率；「黑底白字」只是候選方案，不是通用答案。
gaps: 各任務的最低可接受辨讀閾值尚未建立；第一版只要求記錄，不設統一數字。
```

## 鏡面、螢幕與倒影不在同一平面

常見貼合結構中，數位畫面接近鏡面，但倒影具有鏡後深度。當內容需精準貼合臉部或身體時，觀看位置與雙眼視差會成為問題——「攝影機有抓到臉」不代表「使用者看到的標記會準確貼在臉上」。

```rule
id: POS-01
title: 區分三種內容定位方式，分開設計校準與回饋
normative: should
evidence: cross-domain
tech: both
scope: 任何把數位標記對應到身體或空間的設計。
statement: 明確選用其一：固定在畫面上（時間、說明、狀態）、跟隨身體部位（臉部效果、姿態提示）、位於鏡中空間（倒影的手操作鏡後虛擬物件）；三種模式各配不同的校準與回饋，不共用同一套平面版面規則。
why: 三種模式的誤差來源不同（畫面座標 vs 身體追蹤 vs 觀看視差），混用會讓對齊失敗無從除錯。
wrong: 用同一套 left/top 定位同時處理時鐘顯示與臉部貼紙，左右移動就錯位。
fix: 文件中為每個動態元素標註定位模式；身體跟隨類需註明追蹤來源與更新率，鏡中空間類需註明視點假設。
verify: 使用者左右移動 30 公分，檢查標記是否仍貼合；記錄失效的視角範圍。
gaps: 各追蹤方案的端到端誤差包絡需各團隊實測填入。
```

## 硬體組裝是設計的輸入，不是事後限制

光學元件的第二表面反射可能產生鬼影；觸控相容性與鏡面材料、鍍膜有關，不能把任何半透玻璃視為相同觸控表面。

```rule
id: HW-01
title: 出設計前先確認五項硬體條件
normative: should
evidence: physical
tech: optical
scope: 光學鏡面專案的設計啟動階段。
statement: 下表五項必須有書面確認才能進入視覺設計；任一項未知，對應的設計決策標記為假設，不得簽核。
why: 這些問題不能只靠 UI 修正；事後發現等於重做。
wrong:  فرض所有半透玻璃都可觸控，上線才發現該鍍膜不相容。
fix: 與硬體方逐項簽字；未知項寫入已知缺口並排期驗證。
verify: 對照驗收表逐項勾選，見檢查清單頁。
gaps: 各玻璃供應商的相容性矩陣由各團隊自行建立，本指南不背書特定廠商。
```

| 項目 | 應要求確認的事項 |
|---|---|
| 玻璃與顯示器配置 | 鍍膜方向、間距、鬼影、可顯示範圍與鏡面範圍是否一致 |
| 感測器配置 | 在實際玻璃、照明、角度與遮擋下是否可靠運作 |
| 動態效果 | 使用者動作到數位回饋的端到端延遲，而非只看畫面更新率 |
| 清潔與環境 | 指紋、清潔誤觸、霧氣如何處理；是否需要清潔模式 |
| 裝設與安全 | 操作是否要求不舒服的伸展、後退或轉身；周圍空間是否足夠 |
