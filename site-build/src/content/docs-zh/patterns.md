# 互動模式庫

頁面以任務或問題命名，每頁把元件、狀態與流程連在一起。「按鈕」是元件；「追蹤不穩時讓使用者完成一次可靠選取」才是模式。

| 模式 | 解決的問題 |
|---|---|
| [讓第一次使用者開始互動](start.html) | 沒人教：路人如何知道可以互動、站哪裡、做什麼 |
| [追蹤中斷後恢復操作](recover.html) | 任務中追蹤掉了：如何暫停、恢復並保住信任 |
| [多人靠近時決定誰在控制](handover.html) | 搶控制與交接，不無聲偷走工作階段 |
| [結束體驗並清除個人內容](exit.html) | 完成、取消、清除資料、為下一位重設 |

每個模式頁固定四個區塊：使用指南、互動示範、設計規格、驗證與證據——外加已知缺口。
