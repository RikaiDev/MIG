# 多人、包容性與隱私

距離之外，朝向、移動、身分或角色，以及人與裝置的關係，都會影響互動設計。距離從來不是唯一的答案。

## 主控權與交接

```rule
id: PPL-01
title: 同一時間只有一位可見的主控者，交接走明確路徑
normative: should
evidence: decision
tech: both
scope: 任何超過一個人看得到、摸得到的鏡子。
statement: 同一時間只有一方持有控制權，並明確顯示；第二人加入絕不繼承工作階段——排隊、請求或重新開始。未確認就離開預設結束工作階段。
why: 無聲搶走工作階段是摧毀公共鏡面信任最快的方式；模糊的主控權也會污染評估數據。
wrong: 旁邊朋友一揮手就搶走試穿工作階段；下一位訪客繼承上一位的購物車。
do: 高亮剪影顯示主控者；加入者三選排隊請求重來。
fix: 顯示主控者（例如高亮剪影表同意，不暴露身分）；提供加入／確認後接管／重來；閒置逾時回到吸引狀態。
impl: 雙人測試配暗樁；任何無聲轉移即不合格。
verify: 雙人測試：中途加入第二人；記錄控制權是否在無明確動作下轉移——任何無聲轉移即不合格。
gaps: 高流量場館的公平排隊政策因部署而異。
```

## 身體各不相同

必須驗證的變因：身高、坐姿、輪椅使用、站立距離、手部遮擋、第二人進入。公共情境還要測試「沒有人解說時，能否自行開始」。任何依賴單一身體能力的操作都要有替代路徑——沒有任何任務只能站著、伸手、說話或用看的完成。
