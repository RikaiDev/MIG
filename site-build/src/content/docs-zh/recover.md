# 追蹤中斷後恢復操作

## 使用指南

適用：任何身體跟隨或鏡中空間互動。不適用：無聲重試迴圈——看不見的重試只會教會使用者「這系統是隨機的」。

## 互動示範

到 [Mirror Lab](/zh/lab.html#demo-states) 模擬手離開、辨識失敗、重新捕捉：提交暫停、最後有效狀態凍結並可見、恢復提示寫出確切動作（「把手舉回框內」）。

## 設計規格

- 中斷時：立刻暫停提交；凍結在最後確認狀態；用白話顯示中斷原因，不要只有轉圈圈。
- 恢復必須由原操作者重新進入；不同身體絕不續接工作階段（見 PPL-01）。
- 調參：宣告中斷前的寬限期；重設工作階段前的恢復窗口。

## 驗證與證據

任務中注入追蹤失敗；量恢復成功率、恢復時間、放棄率。通過標準：所有試次零無聲轉移。

## 已知缺口

各情境最佳寬限期未量測；中斷原因分類（遮擋／離開／光線）準確率因感測器而異。
