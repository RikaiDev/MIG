# 研究依據與版本維護

借方法，不抄參數。以下沒有一篇是鏡面裝置規格；每列寫出它貢獻什麼、邊界在哪。

| 研究 | 對本指南的實際貢獻 | 使用證據時的界線 |
|---|---|---|
| **Looking Glass，CHI 2012** | 即時回應路人動作可傳達可互動性（吸引迴圈、開始模式） | 影像式公共顯示器，不是光學半透鏡規格 |
| **Proxemic Interactions，2011** | 靠近—參與—退出的距離／朝向／移動／多人關係鷹架 | 是框架，不是「某固定距離等於同意」的證明 |
| **Consumed Endurance，CHI 2014** | 以手臂生物力學量測持續與重複懸空負擔 | 可移植到鏡面的相關領域證據，不是鏡面直接研究 |
| **AR 試衣間模式，2022** | 從既有系統與文獻整理九個互動模式；借其問題—情境—解法—範例結構 | 試衣零售情境；焦點團體支持不等於大規模驗證 |
| **3D-Mirrorcle，2024 作者版本** | 把倒影與內容的深度位置不一致列為核心問題，原型加使用者研究驗證 | 特定立體顯示配置；一般平面螢幕只改軟體不能宣稱同等效果 |
| **Reverse Vampire UI，CHI EA 2025** | 用倒影的手操作鏡後介面；互動平面本身也是變因 | 12 人先導研究；作者明言不宜推導普遍結論；比較條件有硬體差異 |

值得明說的移植警告：

> **一般鏡子的倒影本來就會跟著人移動，所以「會跟著動」本身絕不證明它是互動系統。**

把 Looking Glass 搬到真鏡面，測的是「可辨識的數位回應」——與手有清楚因果的提示——而不是假設看到自己就會操作。

## 方法參考（學做法，不抄規格）

| 來源 | 借什麼 | 不抄什麼 |
|---|---|---|
| **Ultraleap TouchFree 指南** | 把行為演出來（Guidance；Hover States）；吸引→引導→教會當設計工作 | 非接觸螢幕參數；鏡面光學另補 |
| **Microsoft Mixed Reality：Comfort** | 限制→原因→如何避免→測什麼，把身體與硬體限制寫成規則 | 頭戴裝置的距離角度深度數值當鏡面規格 |
| **GOV.UK Design System patterns** | 任務命名頁面；何時用→如何運作→研究→已知缺口 | 他們領域的內容 |
| **IBM Carbon** | 單頁組織（使用指南／示範／規格／驗證）；正反例加交接 | 元件庫當主角；在這裡模式優先 |
| **日本デジタル庁設計系統（字體排印）** | Noto 家族配對、中文內文 170% 行高、標題 140%、連結必有底線、14px 下限 | 日本行政情境；襯線配對與暖色 token 是我們自己的決定 |

## 版本

語意化。Minor＝新增 proposed 規則。Major＝某次驗證讓規則畢業或撤銷。引用工具必須記錄 MIG 版本。現行：v0.1.0 草稿，暫行，未批准。
