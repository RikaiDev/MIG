# 範圍與使用情境

這份指南的核心是**倒影、數位內容與身體動作之間的關係**，而不是把一般螢幕 UI 放到鏡子上。讀任何規則之前，先回答兩個問題：我做的是哪種鏡子？使用者為什麼站在這裡？

## 兩種鏡面，兩套設計條件

| 類型 | 使用者看到的自己 | 對設計最重要的差異 |
|---|---|---|
| **光學鏡面**：半透半反射鏡＋後方螢幕 | 真實的光學倒影 | 數位內容與倒影疊加；不能單靠軟體任意遮掉倒影；需處理光線、視差與深度 |
| **影像鏡面**：攝影機＋顯示器 | 拍攝、處理後的影像 | 可替換背景、重組畫面；但視角、比例與延遲來自攝影管線，不等同真鏡 |

<strong>第一版以光學鏡面為主，影像鏡面作為對照。每條規則都標明適用技術。</strong>投影、特殊立體顯示、可變透光材料列為延伸範圍，不在第一版涵蓋。

## 使用情境（第一版分類）

不以「有哪些功能」分類，而以使用者為什麼站在這裡分類：

| 情境 | 優先設計目標 | 應特別處理的問題 |
|---|---|---|
| **日常照鏡、資訊瞥視** | 不妨礙原本任務；需要時才介入 | 手忙、濕手、只看一下、被通知打斷 |
| **商店試用、外觀比較** | 看懂變化，保有比較與退出的控制權 | 原始／增強的區別、拍照分享、旁人觀看 |
| **公共展覽、偶遇互動** | 沒人教也知道可以玩、怎麼開始 | 路過與參與的區分、排隊、多人搶控制、交接 |
| **動作與任務引導** | 回饋清楚，操作負擔不干擾主要任務 | 身體被遮住、辨識失敗、延遲、持續舉手的負擔 |

## 不適用條件

- 需要精確醫療診斷或量測的用途：本指南不提供量測精度規範。
- 單純把手機 App 鏡像投到大螢幕：沒有倒影疊加問題，不需要這份指南。
- 尚未確定硬體與安裝現場：光學條件未知的規則只能先讀，不能簽核（見[驗證與部署](/validation.html)）。
