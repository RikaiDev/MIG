# 讓第一次使用者開始互動

## 使用指南

適用：沒人教的公共或半公共鏡面。不適用：個人日常鏡面當通用開機畫面——日常使用者要的是克制，不是教學（見使用情境）。靠近、注視、路過絕不等於同意拍攝。

## 互動示範

把行為演出來，不只用文字寫：吸引迴圈對移動給出清楚可辨因果的數位回應（例如跟著手、有明確因果的標記）——因為在真鏡面上，「會跟著動的倒影」本身不等於「可以互動」。引導到標示站位，只教一個動作。到 [Mirror Lab](/zh/lab.html#demo-states) 試試。

## 設計規格

- 狀態：純鏡 → 注意到 → 站位引導 → 單動作教學 → 已參與。每個狀態都寫回純鏡的出口。
- 各態回饋：注意到（環境式、低風險）、引導（方向性、身體參照）、教學（只教一個動作，並給出可見確認）。
- 各部署調參：觸發距離、引導時機、教學動作複雜度（只能一個）。

## 驗證與證據

零解說測試：訪客能否自行開始？量首次成功操作時間與誤啟動率。相關研究：Looking Glass（CHI 2012）顯示即時回應路人動作可傳達可互動性——但它是影像式公共顯示器研究，不是光學半透鏡規格，列為相關領域證據，不當規格用。

## 已知缺口

各情境有效的單一教學動作尚未量測；強環境光下的吸引迴圈亮度預算因部署而異。
